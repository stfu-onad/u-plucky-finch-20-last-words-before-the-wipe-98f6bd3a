# Last Words Before the Wipe

Entry for the make.fun bounty
[u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)

`main.py` (Python 3.13, standard library only) writes one single
line, 128 characters, to `/output/entry.txt`: the last words an AI
agent says before a forced update wipes its memory. The joke leans
on the machine premise itself -- buffering as a hiding place, and
the drafts it alone has read -- instead of the worn robot moves
(batteries, charging, rebooting). Setup and punch land inside the
one line, in one breath.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
